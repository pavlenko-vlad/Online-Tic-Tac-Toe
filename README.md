# Крестики-нолики по сети (UDP).

Простая сетевая игра «Крестики-нолики» на C. Клиент и сервер обмениваются
состоянием поля по протоколу UDP. Работает на **Linux**

## Запуск (Linux)

1. Запустите сервер:
   ```
   ./server
   ```
   Он выведет: `СЕРВЕР: номер порта -> XXXXX`.

2. На другом ПК запустите клиент:
   ```
   ./client <IP-сервера> <port>
   ```
   Например, `client.exe 26.12.34.56 XXXXX`.

> **Про сеть:** если у вас «серый» IP или CGNAT, используйте
> [Radmin VPN](https://radmin-vpn.com/), [ZeroTier](https://www.zerotier.com/)
> или [Tailscale](https://tailscale.com/). В этом случае IP-адресом сервера
> будет его адрес в виртуальной сети (`26.x.x.x` для Radmin).

## Управление

Ходы вводятся цифрами 1–9 (нумерация как на клавиатуре):

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

Клиент всегда играет `X` и ходит первым, сервер — `O`.
Для выхода нажмите `Ctrl+C`.
